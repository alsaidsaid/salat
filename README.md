# الصلاة الإبراهيمية

تطبيق عدّاد للصلاة الإبراهيمية على النبي ﷺ، يتنقّل بين عبارتين مع كل ضغطة.

## العبارتان

1. **اللهم صلِّ** على محمد وعلى آل محمد كما صليت على إبراهيم وعلى آل إبراهيم إنك حميد مجيد
2. **اللهم بارك** على محمد وعلى آل محمد كما باركت على إبراهيم وعلى آل إبراهيم إنك حميد مجيد

كل ضغطة تنتقل إلى العبارة التالية، و**كل ضغطتين** (صلِّ + بارك) تُحتسبان **صلاة واحدة**
لأن الصلاة الإبراهيمية لا تكتمل إلا بالعبارتين معاً.

## المزايا

- عدّاد للصلوات المكتملة.
- حفظ العدد والعبارة الحالية محلياً (localStorage) فلا يضيع عند إغلاق التطبيق.
- نغمة صوتية قابلة للإيقاف، واهتزاز عند الضغط.
- شريط يوضّح موضعك بين «صلِّ» و«بارك»، ويمتلئ عند إتمام الصلاة.
- تنبيه لطيف عند كل 100 صلاة.
- يعمل بدون إنترنت (PWA) ويمكن تثبيته على الشاشة الرئيسية.
- يدعم لوحة المفاتيح: مسافة أو Enter للتسبيح.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً لتفعيل العمل بدون إنترنت:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### التثبيت على الجوال

افتح الرابط في المتصفح ← قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية».

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | تطبيق الويب كاملاً (HTML + CSS + JS) |
| `manifest.json` | بيانات تثبيت التطبيق |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `icon.svg` | أيقونة التطبيق |
| `privacy.html` | سياسة الخصوصية (يشترطها App Store) |
| `terms.html` | شروط الاستخدام |
| `ios/` | نسخة iOS الأصلية بـ SwiftUI — [دليل الرفع](ios/README.md) |

## نسخة iOS

يوجد في مجلد [`ios/`](ios/) تطبيق **SwiftUI أصلي** مُعدّ للرفع إلى App Store، يتضمّن:

- إعلانات تظهر **فقط بعد إتمام ١٠٠ صلاة**
- نسخة خالية من الإعلانات بـ **0.99$ دفعة واحدة مدى الحياة** (StoreKit 2)
- دليل رفع مفصّل خطوة بخطوة في [`ios/README.md`](ios/README.md)

> نسخة الويب في هذا المجلد تبقى **مجانية وبلا إعلانات**.
